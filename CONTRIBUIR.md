*English first, then Spanish / Primero en inglés, luego en español.*

## EN — How to Contribute to EcoTecNo Global Co. ®

Thank you for taking the time to contribute to EcoTecNo Global Co. ®.

This repository is the public profile of Alfredo Martínez Pastén
(`@alfreddlove83`) and the base of the EcoTecNo Global Co. ® orchestration.

### Principles

- **Do not delete, correct and update.** Changes are corrected and
  updated, noting what changed, why and on what date.
- **Traceability.** Nothing is used without mentioning authorship,
  date and document: where it was obtained from, on which dates
  and in which document.
- **Respect for information.** Do not share passwords, keys,
  verification codes, or personal or fiscal data in commits,
  issues or pull requests.

### Code style

This repository uses `.editorconfig` (root file). Following it is mandatory:

- General: spaces, size 2, LF line endings, UTF-8, no trailing
  whitespace, and a final newline.
- Go: tabs.
- Python and Fish: size 4.
- Markdown: trailing whitespace is not trimmed.

Before submitting a change, check that your editor applies `.editorconfig`.

### How to propose a change

1. Fork the repository and create a branch with a clear name,
   for example `docs/update-readme` or `fix/editorconfig`.
2. Make small, focused changes, one topic per pull request.
3. Write the commit message in clear, direct language,
   for example: `docs: update README with link to CONTRIBUIR.md`.
4. In the pull request description, state what changed, why,
   and what was verified.

### Reporting an issue

Open an issue with:

- What you expected to happen.
- What actually happened.
- Steps to reproduce it, if applicable.
- Date and context in which you saw it.

### Documentation

Documentation can always be improved. If you change a document,
keep standard spelling, up-to-date links, and the provenance
of each piece of data.

## ES — Cómo contribuir a EcoTecNo Global Co. ®

Gracias por tomarte el tiempo de contribuir a EcoTecNo Global Co. ®.

Este repositorio es el perfil público de Alfredo Martínez Pastén
(`@alfreddlove83`) y la base de la orquestación de EcoTecNo Global Co. ®.

### Principios

- **No borrar, sino corregir y actualizar.** Se corrige y se actualiza
  comentando qué cambió, por qué y con qué fecha.
- **Trazabilidad.** Nada se usa sin mencionar autoría, fecha y documento:
  de dónde se obtuvo, en qué fechas y en qué documento.
- **Respeto a la información.** No se comparten contraseñas, llaves,
  códigos de verificación, ni datos personales o fiscales en commits,
  issues o pull requests.

### Estilo de código

El repositorio usa `.editorconfig` (archivo raíz). Respetarlo es obligatorio:

- General: espacios, tamaño 2, fin de línea LF, UTF-8, sin espacios
  al final y con salto de línea final.
- Go: tabuladores.
- Python y Fish: tamaño 4.
- Markdown: no se recortan los espacios al final.

Antes de enviar un cambio, revisa que tu editor aplique `.editorconfig`.

### Cómo proponer un cambio

1. Haz un fork del repositorio y crea una rama con un nombre claro,
   por ejemplo `docs/actualizar-readme` o `fix/editorconfig`.
2. Haz cambios pequeños y enfocados, un tema por pull request.
3. Escribe el mensaje del commit en español, claro y directo,
   por ejemplo: `docs: actualizar README con enlace a CONTRIBUIR.md`.
4. En la descripción del pull request indica qué cambió, por qué
   y qué se verificó.

### Reportar un problema

Abre un issue con:

- Qué esperabas que pasara.
- Qué pasó en realidad.
- Pasos para reproducirlo, si aplica.
- Fecha y contexto en el que lo viste.

### Documentación

La documentación se puede mejorar siempre. Si cambias un documento,
mantén el español estándar, la ortografía y los enlaces actualizados,
y conserva la procedencia de cada dato.
